# dotfiles

1. Install [mise](https://mise.jdx.dev/)
2. Clone this repo with `git clone git@github.com:crbelaus/dotfiles.git ~/.dotfiles`
3. Open the folder with `cd ~/.dotfiles`
4. Apply the dotfiles with `mise bootstrap`. This will symlink the [dotfiles](https://mise.jdx.dev/dotfiles.html) and install the [homebrew packages](https://mise.jdx.dev/bootstrap/packages/)
