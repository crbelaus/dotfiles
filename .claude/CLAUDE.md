# General instructions

A list of general instructions and tooling that must be considered for all projects.

- The `gh` command line tool is available to interact with GitHub.
  - When a GitHub link is pasted let's try to use `gh` to fetch the details when possible.
  - When interacting with GitHub do not make changes unless explicitly told to do so.
- Do not alter the git history yourself unless explicitly told so. This means no commits, no rebases, etc.
